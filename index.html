Supported TikZ & limitations

Use a single tikzpicture, with any macro definitions before it. Basic paths, shapes, colors, arrows, nodes and math labels work. This uses TikZJax, a fixed, limited TeX environment—not a full TeX installation.

Do not paste a full LaTeX document or use \usepackage. Extra TikZ libraries, PGFPlots, custom packages, external files, system fonts, shell escape and LuaLaTeX/XeLaTeX features are not supported here. Unsupported commands may fail or produce incomplete output. Complex code can take time or freeze the render frame.

Rendering stays in your browser; your code is not uploaded. On your first online visit, wait for “Ready for offline use” before disconnecting. The app, compiler and all fonts are then stored in this browser. You can reload, render new code and download while offline. Clearing site data or using a private window removes this offline copy. Downloaded SVGs embed fonts, but labels remain text and may vary in editors that ignore embedded fonts.
